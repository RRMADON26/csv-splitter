Split CSV files online, free and private

This CSV splitter breaks a large file into smaller ones inside your browser. It is built for files that are too big for Excel, an import form or an email attachment, and it keeps every record intact: line breaks inside quoted fields stay in their row, and the header is copied into each part.

How to split a CSV file

  1. Choose a CSV file or drop it onto the page. It is read on your device, not uploaded.
  2. Pick how to split it: rows per file, number of files, maximum size, or one file per value of a column.
  3. Check the strip that shows where the file will be cut, then click Split File.
  4. Download the parts as one ZIP, one at a time, or save them straight into a folder.

Ways to split

  • Rows per file, for example 500,000 rows to stay well inside Excel’s limit of 1,048,576.
  • Number of files, to share the work out evenly.
  • Maximum file size, for upload forms and email limits.
  • Column value, for one file per city, region, month or customer.

Will rows with line breaks be cut in half?

No. The splitter understands quoted fields, so it only cuts between complete records.

Is the header copied into every file?

Yes, as long as “First row is a header” is ticked. Untick it for files without a header.

Can I split by a column?

Yes. Choose Column value and pick the column; you get one file per distinct value, up to 500 values.
