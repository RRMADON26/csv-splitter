How to merge CSV files

Merging CSV files sounds like copying one file under another, and sometimes it is. More often the files came from different exports, and small differences between them turn a simple paste into a mess.

What usually differs between files

  • Column order. One export lists name, id, city, another id, name, city. Pasting them together puts names under the id column.
  • Extra or missing columns. A newer export added a column, or an older one lacks it.
  • Delimiters. Spreadsheet programs in many European locales save CSV files with semicolons instead of commas.
  • Encodings. Files saved on different systems may use UTF-8 or Windows-1252, so the same name appears correctly in one and garbled in the other.
  • Repeated headers. Gluing files together by hand leaves a header row in the middle of the data.

Two ways to combine rows

Keep columns as they are appends the rows of each file in order and keeps a single header at the top. It is the right choice when every file has exactly the same columns in the same order.

Match columns by name builds the output from every column name found in any file, in order of first appearance, and puts each value under its own column. Cells for columns a file doesn’t have are left empty. Use it whenever the files are not identical.

Step by step

  1. Open the Merge tool and add all the files at once. Each file’s encoding and delimiter are detected automatically.
  2. Drag the files into the order you want the rows to appear. The first file is the reference, and any file whose columns differ from it is flagged.
  3. Choose Match columns by name if any file is flagged.
  4. Optionally tick Add a column with the source file name. It makes it easy to see later which rows came from where.
  5. Under Format details, pick the delimiter and encoding of the result, then click Merge Files.

Check the result

The merged file should contain as many rows as all the input files together. The summary after merging shows that total and how many files had different columns. Open the result and look at a few rows from each source, especially near the start of the second and third files, where problems tend to show up.

Tips

  • Column names must match exactly to be combined. “Email” and “E-mail” count as two different columns; rename one first in the Transform tool.
  • If the same records appear in several files, run the result through Transform’s Remove duplicates step.
