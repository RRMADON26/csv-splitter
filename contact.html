Contact

CSV Toolkit is developed in the open, so the best way to reach the maintainer is on GitHub.

Report a problem or suggest a feature

Open an issue on the GitHub issue tracker. Describe what you were doing, what you expected and what happened instead. If a file causes the problem, please share a small sample with any private data removed, never the original.

Privacy and other questions

Questions about privacy, the terms or anything else are welcome on the same issue tracker. Please don’t post personal information there, since issues are public.

Source code

The code is available at github.com/RRMADON26/csv-splitter.
