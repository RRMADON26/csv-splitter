Merge CSV files online, free and private

This tool combines several CSV files into a single file, directly in your browser. It handles the differences that usually make merging painful: columns in a different order, extra columns in some files, semicolon and comma delimiters, and files saved in different encodings.

How to merge CSV files

  1. Add all the files at once, by choosing them or dropping them onto the page.
  2. Drag them into the order the rows should appear. Files whose columns differ from the first one are flagged.
  3. Choose Match columns by name if any file is flagged, and optionally add a column with each row’s source file.
  4. Click Merge Files and download the result.

What if the files have different columns?

Match columns by name builds the output from every column found in any file and leaves cells empty where a file has no value.

Do the files need the same delimiter?

No. Each file’s delimiter and encoding are detected separately, and you choose the delimiter and encoding of the merged file.

Is the header repeated in the middle?

No. The merged file has a single header row at the top.
