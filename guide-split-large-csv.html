How to split a large CSV file

Big CSV exports run into limits all the time: Excel stops at 1,048,576 rows, import forms reject files above a certain size, and email providers cap attachments. Splitting the file into smaller parts is usually the simplest fix, as long as it is done carefully.

Why splitting “by lines” can go wrong

A CSV looks like one record per line, but that is not always true. A field wrapped in double quotes may contain a line break, for example an address written on two lines or a comment with several paragraphs. A tool that cuts the file every n lines, such as the Unix split -l command, can slice one of those records in half. The result is two broken files: one ending with half a row, the next starting with the other half.

The second common problem is the header. Only the first part keeps the column names, so every later part is harder to import and easy to misread.

A safe split therefore needs to understand quotes, so that it only cuts between records, and it should repeat the header in every part.

Choose how to divide the file

  • Rows per file is the most common choice. Pick a number below the limit of wherever the files are going, for example 500,000 rows for comfortable work in Excel.
  • Number of files is useful when you want to share the work out, for example four equal parts for four people.
  • Maximum file size fits upload forms and email: tell it “10 MB” and each part stays under that size, including the header.
  • Column value creates one file per distinct value, such as one file per city, region or month. This is often what people really want when they split a report.

Step by step

  1. Open the Split tool and choose your file, or drop it onto the page. The file is read on your device and is not uploaded.
  2. Check the file panel. It shows the number of rows and columns, and whether the first row is treated as a header. Untick that box if your file has no header.
  3. Pick how to split and enter a number. The strip at the top shows where the file will be cut before anything runs.
  4. Click Split File. When it finishes, download every part as one ZIP, download parts one at a time, or, in Chrome and Edge, save them straight into a folder.

Check the result

A quick sanity check catches most mistakes. The row counts of the parts should add up to the row count of the original file, and every part should open with the same header. If you split by column value, the summary lists how many rows went into each file.

Tips

  • If accents or symbols look wrong in the parts, the original was probably read with the wrong encoding. See fixing garbled characters.
  • Keep the original file. Splitting never changes it, but it is the copy you will want if you need to split differently later.
  • For files with more than a few million rows, saving to a folder avoids holding every part in memory at once.
