Validate and preview CSV files

Open a CSV to see what is inside before you import it anywhere. The validator previews the first rows, works out what kind of data each column holds, and lists problems that commonly break imports, all without uploading the file.

What it checks

  • Rows with more or fewer columns than the header
  • Unclosed quotes and undecodable characters
  • Garbled text caused by reading UTF-8 as Windows-1252
  • Duplicate or missing column names and completely empty columns
  • Leading and trailing spaces, mixed value types, mixed line endings

Column statistics

For every column you get the detected type (integer, decimal, date, boolean or text), how full it is, the number of distinct values, the range of numbers or dates and the most common values. Issues and statistics can both be exported as CSV.

Does the validator change my file?

No. It only reads the file. Use Clean to trim spaces, filter rows or remove columns.
