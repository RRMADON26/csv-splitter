About CSV Toolkit

CSV Toolkit is a set of free tools for everyday work with CSV files: splitting big files, merging several files, finding problems in the data, cleaning and filtering rows, and converting to Excel or JSON.

How it works

Everything happens inside your web browser. When you open a file, the page reads it in small chunks with JavaScript, does the work on your own computer or phone, and hands the result back to you as a download. There is no server that receives your data, so the tools work the same whether your file holds a shopping list or customer records.

Reading in chunks is also what lets the tools handle large files. A CSV with hundreds of thousands of rows is processed without freezing the page, and line breaks inside quoted fields (an address on two lines, for example) are kept inside their row instead of breaking the file apart.

The tools

  • View opens a whole file so you can scroll, search and sort every row.
  • Split breaks a file into parts by row count, number of files, file size, or by the value of a column.
  • Merge combines several files into one and can match columns by name.
  • Inspect previews the data, describes every column and lists problems such as rows with the wrong number of columns.
  • Transform trims cells, filters rows, removes duplicates, takes samples and picks, renames or reorders columns.
  • Convert produces TSV, JSON, JSON Lines or a real Excel workbook, and can change the text encoding.

Who makes it

CSV Toolkit is an open-source project maintained by RRMADON26. The full source code is on GitHub, where you can read exactly what the page does with your files, report a problem or suggest a feature.

How it stays free

The tools cost nothing to use. The site shows a small number of ads from Google AdSense to cover hosting. Ads are kept away from the buttons you use to run the tools and download results, and they never have access to your files. See the privacy policy for how ad cookies work.
