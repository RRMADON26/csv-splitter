Clean, filter and de-duplicate CSV files

Turn a messy export into the file you actually need. Each step can be switched on or off, and a live preview shows the result on the first rows of your file before anything runs.

The steps

  1. Clean cells: trim spaces and flatten line breaks inside cells.
  2. Filter rows: keep rows that match rules such as “city equals Jakarta” or “amount is at least 100”.
  3. Remove duplicates: by the whole row or by selected columns.
  4. Sample rows: the first N rows, a random N rows, a random percentage or every Nth row.
  5. Columns: keep, rename and reorder columns.

How do I remove duplicate rows from a CSV?

Turn on Remove duplicates. Choose whether two rows count as duplicates when the whole row matches or only selected columns, then run the tool. The first occurrence is kept.

Can I filter with more than one condition?

Yes. Add as many rules as you need and choose whether all or any of them must match.

Is a random sample in the original order?

Yes. Rows in a random sample keep the order they had in the file.
